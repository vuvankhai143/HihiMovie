# HihiMovie

Trang quản trị phim cho app TV HihiMovie: https://vuvankhai143.github.io/HihiMovie/

- `data.json`: danh sách phim, tập, playlist M3U và danh mục. App TV đọc file này.
- `auth.json`: token GitHub đã mã hoá bằng tên đăng nhập + mật khẩu admin.
- `app.apk`: file cài app cho TV, tải tại https://vuvankhai143.github.io/HihiMovie/app.apk

Quên mật khẩu hoặc token hết hạn: mở trang với `?setup` ở cuối địa chỉ để thiết lập lại.
