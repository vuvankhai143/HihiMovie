# TV Phim Admin

Trang quản lý phim cho app TV Phim: https://vuvankhai143.github.io/tvphim-admin/

- `data.json`: danh sách phim, playlist M3U và danh mục. App TV đọc file này.
- `auth.json`: token GitHub đã mã hoá bằng tên đăng nhập + mật khẩu admin.

Quên mật khẩu hoặc token hết hạn: mở trang với `?setup` ở cuối địa chỉ để thiết lập lại.
